FlClash macOS 使用教程

安装 FlClash，导入 Web3X 订阅，选择节点并测试连接。

  • 安装和首次打开
  • 导入订阅
  • 选择节点并连接
  • 设置 Wi‑Fi 代理

1. 安装和首次打开

  1. 双击 FlClash 安装包，将 FlClash 图标拖入 Applications（应用程序）文件夹。
  2. 关闭安装窗口，在访达的「应用程序」中双击 FlClash。
  3. 如果 macOS 提示无法验证应用，先确认安装包来自可信来源，再前往「系统设置 → 隐私与安全性」，找到 FlClash 提示并选择「仍要打开」。在确认窗口中再次选择「仍要打开」。
  4. 阅读 FlClash 首次启动时的免责声明，同意后进入仪表盘。

2. 导入订阅

  1. 在 Web3X 主页的订阅管理中点击「查看订阅」，复制 FlClash 订阅链接。也可以使用客服消息里提供的订阅链接。
  2. 在 FlClash 左侧打开「配置」，点击右下角的「＋」，选择「URL」。
  3. 粘贴链接并点击「提交」。导入完成后，点击列表中的配置卡片选用该配置。
{{ screenshot('profiles', '在配置页面点击右下角的加号') }} {{ screenshot('add-profile', '选择 URL 导入方式') }} {{ screenshot('import-url', '粘贴订阅链接并提交') }}

3. 选择节点并连接

  1. 如果订阅提供 IPv6 节点且当前网络支持 IPv6，在「工具 → 基本配置」中开启 IPv6。
  2. 打开「代理」页面，点击右下角的测速按钮，在「节点选择」中选一个有延迟数值的节点。
  3. 返回「仪表盘」，启用「系统代理」，点击右下角的启动按钮。出现运行计时后，在浏览器中打开网页测试连接。

4. 设置 Wi‑Fi 代理

如果 FlClash 已启动且开启了系统代理，但浏览器仍无法连接，可检查 macOS 的 Wi‑Fi 代理设置。

  1. 打开「系统设置 → Wi‑Fi」，点击当前网络旁的「详细信息」，再从左侧选择「代理」。
  2. 如需手动设置，开启「网页代理（HTTP）」和「安全网页代理（HTTPS）」，两项的服务器都填 127.0.0.1，端口填 FlClash「工具 → 基本配置」里显示的端口。原稿以 7890 为例。
  3. 保存后回到浏览器重试。停止使用 FlClash 时，关闭手动设置的代理。
